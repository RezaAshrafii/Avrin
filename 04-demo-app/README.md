# دموی محلی هتل اورین

این پروژه یک پیش‌نمایش محلی فارسی و راست‌به‌چپ برای بررسی طراحی هتل، اتاق‌ها، رستوران، منو و جریان‌های نمونه است. به سامانهٔ رزرو، درگاه پرداخت، پیامک، OTP یا API فروشگاه منو وصل نیست و هیچ فرم مهمان اطلاعاتی به شبکه نمی‌فرستد.

## پیش‌نیاز و اجرا

- Node.js `24.19.0` در محیط سازنده؛ Next.js نسخهٔ نصب‌شده در `package-lock.json` ثبت شده است.
- در این پوشه: `npm install`، سپس `npm run dev`.
- نشانی پیش‌فرض: `http://localhost:3000/fa`. در صورت اشغال پورت، Next پیام پورت جایگزین را چاپ می‌کند.
- کنترل‌ها: `npm run lint`، `npm run typecheck`، `npm test` و `npm run build`.
- برای بازسازی داده و رسانه از بستهٔ اصلی: `npm run import:avrin` (مسیر منبع اختیاری: `node scripts/import-avrin.mjs <kit-root>`). این فرمان فقط دادهٔ ورودی را می‌خواند و مشتق‌های تازه را در پروژه می‌نویسد.

## مسیرها

`/fa`، `/fa/rooms`، هشت مسیر `/fa/rooms/<slug>`، `/fa/book`، `/fa/book/confirmation`، `/fa/restaurant`، `/fa/restaurant/menu`، `/fa/restaurant/cart`، `/fa/restaurant/order-preview`، `/fa/gallery`، `/fa/about`، `/fa/facilities`، `/fa/contact`، `/fa/faq`، `/fa/policy` و `/fa/privacy` پیاده شده‌اند. `/` به `/fa` می‌رود. مسیرهای قدیمی facalities، blog، en، virtual و shop در `next.config.ts` مقصد موقت دارند.

## داده و عکس

دادهٔ زمان snapshot در `src/data/site-data.json` است. ورودی خام ۲۴۴ محصول/۳۱ دسته نگه داشته می‌شود؛ منوی مشتری از ۲۳۴ محصول/۲۸ دسته استفاده می‌کند. محصولات عکس عمومی، عکس ناموجود و ده تصویر مشترک در حالت بدون عکس می‌مانند. منبع تصویری در runtime درخواست نمی‌شود. تصاویر مشتق‌شده فقط با sharp، بدون بزرگ‌نمایی و با حفظ تناسب تولید شده‌اند. عکس‌های اصلی در `../01-assets/` دست‌نخورده‌اند.

قیمت منو به تومان نمایش داده می‌شود. نرخ اتاق عمداً خالی است. تمام سبدها، نتایج سفارش و برنامه‌های اقامت برچسب نمایشی دارند.

فرم جست‌وجوی اقامت در صفحهٔ خانه از تقویم جلالی سفارشی با اعداد فارسی و کنترل ورود/خروج استفاده می‌کند. بازبینی نهایی لینک‌ها و کنترل‌های تعاملی در `FINAL_REVIEW.md` و `artifacts/screenshots/browser-review.json` ثبت شده است.

## فایل‌های کنترل

- `IMPLEMENTATION_STATUS.md` وضعیت P0 تا P6 و معیارهای پذیرش را ثبت می‌کند.
- `CONTENT_REVIEW.md` تأییدهای مدیریتی و محتوایی را فهرست می‌کند.
- `ASSET_USAGE.md` نقش عکس‌های مجاز، مشتق‌ها و دارایی‌های بلاک‌شده را مشخص می‌کند.
- `artifacts/screenshots/` مدارک گرفته‌شده از اجرای محلی را نگه می‌دارد.

## فناوری

Next.js App Router، React، TypeScript strict، CSS سراسری با توکن‌های جداگانه (فعلاً بدون ماژول‌بندی CSS)، sharp و jalaali-js. صفحه‌ها سروری‌اند؛ اجزای تعاملی در `DemoPage` اجرا می‌شوند. داده و عکس از سایت زنده fetch نمی‌شوند.
