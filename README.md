# Avrin — هتل، کافه و رستوران

این مخزن شامل بستهٔ منبع و دموی فارسی هتل اورین، شامل سایت هتل و مسیرهای کافه/رستوران و منوی نمایشی است. کد اجرایی در `04-demo-app/` قرار دارد و هر دو بخش با همان اپ Next.js منتشر می‌شوند:

- خانه و صفحه‌های هتل: `/fa`، `/fa/rooms`، `/fa/gallery`، `/fa/about`، `/fa/facilities`، `/fa/contact`، `/fa/faq` و صفحه‌های مرتبط
- کافه و رستوران: `/fa/restaurant`، `/fa/restaurant/menu`، `/fa/restaurant/cart` و `/fa/restaurant/order-preview`

## استقرار روی Vercel

1. در Vercel وارد **Add New → Project** شوید و مخزن خصوصی `RezaAshrafii/Avrin` را وارد کنید.
2. در تنظیمات پروژه، **Root Directory** را روی `04-demo-app` بگذارید و ذخیره کنید. این پوشه فایل `package.json` و `package-lock.json` اپ را دارد.
3. چارچوب باید به‌صورت خودکار **Next.js** تشخیص داده شود. تنظیمات عادی نصب و build را نگه دارید؛ فرمان build برابر `npm run build` است. متغیر محیطی لازم نیست.
4. **Deploy** را بزنید. Vercel یک نشانی قابل نمایش با پسوند `vercel.app` می‌سازد. هر دو سایت از همان نشانی در مسیرهای بالا در دسترس خواهند بود.
5. برای دامنهٔ اختصاصی، پس از انتخاب دامنه در **Project → Settings → Domains** آن را اضافه کنید و رکوردهای DNS دقیقی را که Vercel برای همان دامنه نشان می‌دهد، در پنل ثبت‌کنندهٔ دامنه وارد کنید. پس از تأیید DNS، HTTPS خودکار فعال می‌شود.
6. پس از اتصال Git، هر push به شاخهٔ اصلی یک استقرار جدید می‌سازد؛ شاخه‌های دیگر نیز برای بازبینی می‌توانند پیش‌نمایش جداگانه داشته باشند.

برای ساخت پروژهٔ جداگانهٔ Vercel برای رستوران لازم نیست: رستوران و هتل در همین اپ هستند. اگر بعداً بخواهید، می‌توان دامنه یا زیردامنهٔ دیگری را نیز به همین پروژه وصل کرد و آن را به مسیر رستوران هدایت کرد.

## ساختار مخزن

- `01-assets/` عکس‌ها و دارایی‌های اصلی گردآوری‌شده؛ فایل‌های قرنطینه‌شدهٔ عکس عمومی غذا برای استفاده در رابط کاربری نیستند.
- `02-source-data/` snapshot داده، فهرست مسیرها، منو و ممیزی تصاویر.
- `03-demo-plan/` نقشه و تصمیم‌های طراحی دموی اختصاصی اورین.
- `04-demo-app/` اپ Next.js، کد، تصویرهای بهینه‌شدهٔ مورد نیاز سایت، گزارش کنترل و مدارک بازبینی.

## اجرای محلی

نیازمند Node.js و npm است. در پوشهٔ `04-demo-app/` اجرا کنید:

```powershell
npm ci
npm run dev
```

سپس `http://localhost:3000/fa` را باز کنید. جزئیات مسیرها و کنترل‌های پروژه در `04-demo-app/README.md` آمده است.

## محدودیت‌های دمو

این خروجی برای نمایش و بازبینی است. رزرو واقعی، موجودی و نرخ زندهٔ اتاق، ثبت سفارش، درگاه پرداخت یا ارسال سفارش به رستوران متصل نیست. قیمت‌ها و محتوای منو snapshot هستند. لطفاً پیش از استفادهٔ تجاری، موارد داخل `04-demo-app/CONTENT_REVIEW.md` را با مدیریت اورین تأیید کنید. تصاویر عمومی یا ناموجود منوی غذا نباید به‌عنوان عکس واقعی محصول نمایش داده شوند.
